# CloudHealth Technologies

> CloudHealth Technologies is a cloud financial management (FinOps) and multi-cloud governance platform (originally Kleiner Perkins-backed, acquired by VMware in 2018, now sold as CloudHealth by Broadcom) that analyzes and optimizes cloud cost, usage, security, and governance across AWS, Azure, and Google Cloud. It exposes a REST API and a GraphQL API for programmatic access to accounts, assets, perspectives, billing rules, metrics, OLAP reports, policies, tagging, SSO, and organization/partner administration.
